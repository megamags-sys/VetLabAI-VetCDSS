# VetLabAI-VetCDSS

Veterinary Clinical Decision Support System (Vet-CDSS).

## V0.1.0-alpha

Initial milestone:
- MRN as the primary patient identifier
- Analysis ID for each analysis event
- Patient data model
- Standardized Vet-CDSS report header
- CLI case creation and Markdown report generation
- SQLite-ready architecture

Clinical safety: decision-support software only; it does not replace professional veterinary judgment, examination, laboratory validation, or current clinical guidelines.

## Run

```bash
python main.py
```

## Test

```bash
python -m pytest
```
